# Data Engineering for Prompt Optimization

An offline walkthrough for a talk on setting up the pipeline around a prompt optimizer (GEPA). Press Next
to step through it: a prompt improves from a one-liner, gets a score, then meets GEPA.

```bash
open index.html                    # present it
python3 build.py                   # rebuild after editing src/template.html
node scripts/verify-numbers.js     # recompute every displayed score
```

Keys: Next and Previous (arrow keys), Jump menu in the header, N for speaker notes.

The toy screens use invented data and say so on screen. The "Real data" screen uses Eklavya's own
result notes. Read `CLAUDE.md` before changing anything.
